Open source

Merged patches in the stacks agents actually use.

A tool-loop on this repo searches GitHub, ranks agent/MCP/RAG/inference patches, and writes the list below. Expand the run to see the tools it called.

  • AG-UI Emit TOOL_CALL triple before RESULT on resume of a suspended tool.
  • Spec Kit Resolve assess clarifications by editing artifacts in place.
  • FastMCP Emit WWW-Authenticate on 401 when authenticate() fails with no OAuth config.
  • Haystack Raise a clear error when type routers reuse reserved output names.
  • mlx-lm Rebind BatchKVCache offset instead of mutating in place.
  • Chainlit Fail CI when a pnpm.overrides pin is declared but never applied.
  • Logfire Keep tail-sampling buffers until every span in the trace has ended.
